# Ritesh Jadhav - Portfolio

A responsive, single-page portfolio for Ritesh Jadhav, an aspiring Java full-stack developer based in Pune, India. The site is built with plain HTML, CSS, and JavaScript and does not require a build step or external dependencies.

## Features

- Responsive layout for desktop and mobile
- Dark and light themes, with the selected theme saved in browser storage
- About, education, featured projects, skills, and contact sections
- Scroll-triggered reveal animations
- Email, LinkedIn, and GitHub profile links

## Run locally

Open `index.html` in a web browser, or open the project folder in Visual Studio Code and run it with the Live Server extension.

## Publish with GitHub Pages

1. Push the project to a GitHub repository.
2. In the repository, open **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then save.
5. Once deployment completes, the site will be available at `https://<username>.github.io/<repository>/`.
